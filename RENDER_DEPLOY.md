# Инструкция по деплою API на Render

Привет, братиш! Чтобы наш гольф-календарь работал не только в оффлайн-режиме, но и тянул актуальные данные с сервера, нужно поднять бэкенд на Render. Это бесплатно, надежно и делается за 10 минут.

### Шаг 1: Подготовка
1. Зарегистрируйся на [Render.com](https://render.com/).
2. Сделай «Fork» нашего репозитория `ndvtwww-altushka/mir-golfa` в свой аккаунт GitHub.

### Шаг 2: Создание Web Service
1. В личном кабинете Render нажми **"New +"** → **"Web Service"**.
2. Выбери подключение к GitHub и найди свой форк `mir-golfa`.
3. В настройках:
   - **Name**: `mir-golfa-api` (или любое другое).
   - **Environment**: `Docker`.
   - **Branch**: `main`.
   - **Root Directory**: `backend` (обязательно укажи эту папку!).
4. Нажми **"Advanced"** и добавь Environment Variable:
   - `GOLF_ADMIN_TOKEN`: придумай сложный пароль (например, `my_secret_token_123`). Он нужен для синхронизации данных.
5. Выбери **"Free"** план.
6. Нажми **"Create Web Service"**.

### Что важно знать:
*   **Сон**: На бесплатном тарифе Render "засыпает" после 15 минут простоя. Первый запрос после сна может идти секунд 20-30.
*   **База данных**: Мы используем SQLite внутри контейнера. При каждом перезапуске сервера (если ты поменяешь код) данные будут сбрасываться. Это ок — приложение само восстановит их при следующей синхронизации.
*   **Health Check**: Сервер сам скажет Render, что он жив через `/api/v1/health`.

### Как настроить приложение:
В самом приложении (в APK) зайди в раздел **"Ещё"** → **"Настройки"**. Там будет поле "Адрес API". Вставь туда ссылку, которую даст тебе Render (выглядит как `https://...onrender.com`), и укажи свой `GOLF_ADMIN_TOKEN`.

Все готово, братиш! Теперь у тебя полноценный гольф-сервис.
