# Changelog

## 2.1.0 — приложение, которое работает без сервера

- Мобильное приложение переписано: четыре вкладки (Турниры, Моя игра, Клубы, Ещё),
  собственный дизайн-система, карточки событий с обратным отсчётом и группировкой по месяцам.
- Каталог турниров вшит в сборку (`mobile/src/data/bootstrap.json`) — приложение работает
  офлайн, сервер нужен только для свежих данных и модерации.
- Наполнение из официального календаря АГР: `tools/sync_calendar.py` разбирает страницу
  сезона и собирает seed + bootstrap. Сейчас 42 события (37 АГР + 5 Forest Hills).
- Ежедневная синхронизация в GitHub Actions с проверкой «не меньше 10 событий» —
  защита от тихой поломки разбора при смене вёрстки.
- Слои данных: `api.js` (сеть + fallback), `offline.js` (локальный движок фильтров и статусов),
  `storage.js` (AsyncStorage), `format.js` (даты, статусы, отсчёт).
- Раздел «Моя игра»: журнал раундов, оценка гандикапа по лучшим 40% дифференциалов,
  средний счёт, патты, GIR, фервеи и график отклонения от пара.
- Раздел «Ещё»: реестр источников со степенью авторитетности, настройка адреса API,
  форма заявки организатора, ссылки на APK и исходники.
- Сборка APK через GitHub Actions: prebuild → Gradle release → zipalign → apksigner,
  публикация в релиз `apk-latest` (стабильная ссылка на скачивание).
- Веб-версия (Expo web export) публикуется на GitHub Pages.
- `render.yaml` и `backend/Dockerfile` — деплой API на Render в один клик.
- `backend/app/domain.py`: запасной часовой пояс MSK, если в окружении нет tzdata.
- Добавлены `tools/make_icon.py` (иконки на чистом Python) и DEPLOY.md.

## 2.0.0 — продуктовый реворк

- Исправлена структура директорий и стандартные имена entrypoint-файлов.
- Добавлены FastAPI API, SQLite schema, единый реестр источников и тестовые факты с provenance.
- Добавлены архив, фильтры, персональные рекомендации, клубный каталог, verified-only результаты, analytics, ICS export.
- Добавлены заявка организатора, предложения исправлений, admin moderation endpoints и журнал изменений.
- Статус прошедших дат стал «не подтверждён», а не «завершён» по догадке.
- Добавлены пять этапов «Зимнего кубка Форест Хиллс 2026–2027» из положения с полными требованиями, ценой, адресом и контактами; HCP-группы не упрощены до неверного общего диапазона.
- Добавлен монитор источников с отказом по неуспешному robots.txt, лимитом размера, задержкой на host и проверкой redirect host.
- Добавлены 18 unit/integration tests.
- Добавлены два адреса площадок из положения организаторов и личный локальный журнал раундов с расчётом score/putts/GIR/fairways.
