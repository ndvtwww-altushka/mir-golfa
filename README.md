# Мир Гольфа

**Турниры. Клубы. Результаты.**

Мобильное приложение и API с календарём турниров по гольфу и мини-гольфу в России и СНГ.
Сейчас в каталоге **42 события сезона 2026/27**, из них 37 перенесены из официального
календаря Ассоциации гольфа России, а 5 этапов Зимнего кубка «Форест Хиллс» — из положения
организаторов.

Главное правило: **данные не додумываются**. Если прошедшая дата не означает «турнир
состоялся», приложение так и пишет. Если нет официального протокола — победителя нет.

---

## Что умеет

| Раздел | Возможности |
|---|---|
| **Турниры** | Календарь по месяцам, поиск, фильтры по виду, региону и уровню, избранное, карточка события со ссылкой на первоисточник, обратный отсчёт до старта |
| **Моя игра** | Личный журнал раундов (9/18 лунок, счёт, патты, GIR, фервеи), оценка гандикапа, график отклонения от пара, средние показатели |
| **Клубы** | Каталог площадок с проверенным адресом, картой, телефоном и ссылкой на источник |
| **Ещё** | Реестр источников, настройка адреса API, форма заявки организатора, честная статистика базы |

Приложение **работает офлайн**: каталог вшит в сборку (~50 КБ), сервер нужен только для
свежих данных и модерации.

## Структура

```
mobile/                 Expo SDK 58 + React Native 0.88
  src/App.js            оболочка, вкладки, состояние
  src/screens/          Турниры · Моя игра · Клубы · Ещё
  src/offline.js        локальный движок: фильтры и статусы без сервера
  src/data/            bootstrap.json (генерируется)
  src/format.js         даты, статусы, обратный отсчёт

backend/                FastAPI + SQLite
  app/domain.py         правила статусов и допуска (без HTTP и БД)
  app/main.py           API: каталог, клубы, результаты, заявки, модерация
  data/*.seed.json      источники, события, клубы
  tests/                доменные и интеграционные тесты

tools/
  sync_calendar.py      разбор календаря АГР → seed + bootstrap
  make_icon.py          иконки без зависимостей (чистый Python)

.github/workflows/
  android.yml           сборка и подпись APK → релиз
  pages.yml             экспорт веб-версии → GitHub Pages
  sync-data.yml         ежедневное обновление календаря
```

## Запуск

### Приложение

```bash
cd mobile
npm install
npx expo start          # Expo Go или эмулятор
npm run export:web      # статическая веб-версия в dist/
```

### API

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Docs: `http://127.0.0.1:8000/docs`. Админ-эндпоинты включаются переменной
`GOLF_ADMIN_TOKEN`.

### Обновление данных

```bash
python3 tools/sync_calendar.py          # скачать и пересобрать
python3 tools/sync_calendar.py --check  # только проверить разбор
python3 tools/make_icon.py              # перерисовать иконки
```

## API

| Метод | Что делает |
|---|---|
| `GET /api/v1/tournaments` | каталог: поиск, фильтры, `limit`/`offset` |
| `GET /api/v1/tournaments/{id}` | карточка + история подтверждений по полям |
| `GET /api/v1/recommendations` | подбор по региону, возрасту и гандикапу |
| `GET /api/v1/clubs` | каталог клубов |
| `GET /api/v1/results` | только официальные результаты |
| `GET /api/v1/sources` | реестр источников и режим сбора |
| `GET /api/v1/stats/overview` | состояние базы |
| `GET /api/v1/calendar.ics` | экспорт в календарь |
| `POST /api/v1/organizer/submissions` | заявка организатора (на модерацию) |
| `POST /api/v1/tournaments/{id}/corrections` | исправление с доказательством |
| `/api/v1/admin/*` | модерация, требует `X-Admin-Token` |

## Откуда данные

| Источник | Уровень | Режим |
|---|---|---|
| Ассоциация гольфа России — календарь | федерация | разбор включён |
| АГР — положения и документы | федерация | ручная проверка |
| Федерация гольфа Москвы | федерация | ручная проверка |
| Москомспорт | город | ручная проверка |
| Федерация гольфа Московской области | федерация | ручная проверка |
| Гольф.ру (любительские турниры) | агрегатор | ручная проверка |
| Белорусская ассоциация гольфа | федерация | ручная проверка |
| Казахстанская федерация гольфа | федерация | ручная проверка |
| UZGolf / WAGR | агрегатор / рейтинг | справочно |

Статус `crawl_approved` означает техническую готовность к сбору, а не подтверждение
каждого события. Перед включением автоматического сбора нужно проверить условия
использования сайта и `robots.txt`.

## Тесты

```bash
PYTHONPATH=backend python -m unittest discover -s backend/tests -v
```

Проверяются: прошедшие даты не превращаются в «завершён», отмена важнее дат,
отсутствие ограничения не означает отказ, результаты без протокола не публикуются,
заявка не попадает в календарь до модерации.

## Ограничения

- Это не официальный продукт АГР. Даты и статусы проверяйте у организатора.
- Покрытие СНГ зависит от доступности первоисточников; сейчас автоматически
  собирается только календарь АГР.
- Личный гандикап в приложении — оценка, а не официальный WHS.
- Ключ подписи `signing/release.jks` лежит в репозитории, чтобы сборки обновлялись
  «поверх». Для Google Play сгенерируйте отдельный и держите его в секретах.
